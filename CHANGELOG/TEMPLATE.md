# Surface history entry template

Use one append-only history per changed surface. Link its current file and this [history index](README.md). Record only work and evidence that actually occurred.

## YYYY-MM-DD — Concrete change

- Surface: relative link to the changed file.
- Reason: who needed to do what, and what went wrong.
- Before / after: the observed problem and the resulting behavior.
- Evidence: exact source or runtime checks, inputs, outputs and verification scope.
- Limits: what remains unresolved or unverified.
